## Phase 1.5: Collaborative operators + settings
- [x] **Настройки системы (Settings Page)**:
  - Доступны только пользователям с ролью `admin` (`is_admin=True`, пароль `10072025`).
  - Управление сетевыми параметрами ролей (IP для отдела фасовки `ip_facade`, маркировки `ip_labeling`, операторов `ip_operator`).
  - Флаг `is_admin` в модели `User`.
- [x] **Совместное выполнение заказов (Multiple Operators per Order)**:
  - Новая модель `OperatorSession` для параллельной работы операторов над одним заказом.
  - Изменение статусов задач (`pending` -> `in_progress` -> `completed`).
  - Кнопка «Взять в работу» для нового заказа и «Продолжить» для создания дополнительной сессии другим оператором.
  - Отображение общего прогресса («Наклеено: 32 / 120 (2 оператора)») и кнопок инкремента только для своей активной сессии.
  - Автоматическое переключение заказа в `completed` при достижении целевого количества.
  - Убран остаток неиспользованных стикеров из интерфейса оператора.
  - Двухвкладочный интерфейс оператора («Мои сессии» и «Общий список»).
  - Статистика по времени выполнения заказа (сумма времени сессий), количеству операторов и среднему времени сессии.
  - Логирование всех изменений в сессиях операторов.
- [x] **Partial labeling, Excel import & defect tracking**:
  - Импорт базы товаров из Excel (`/facade/products/import-excel`).
  - Ручная установка даты производства (`production_date`) оператором фасовки и менеджером фасада.
  - Правило создания заказов до 12:00 и поле основания срочности (`urgency_reason`) при заказе после 12:00.
  - Частичная обклейка (Pause / Resume / Частичное завершение).
  - Ограничение: не более 1 активной (running) сессии у оператора.
  - Фиксация даты фактической обклейки (`actual_labeling_date`) и времени полного завершения (`actual_completed_at`).
  - Учет брака (`defect_qty`) и отображение в отделе маркировки и фасада.
  - Страница сводки за день `/today`.
- [x] **Скрипт первоначального заполнения (`seed.py`)**:
  - Создание 1 администратора (`admin`, пароль `10072025`) и 2 операторов (`op1`, `op2`).
  - Создание заказа со статусом `in_progress` и 2 активными сессиями.
