# Инструкция по запуск и сборке MALVIK-LABEL (EXE)

Приложение **MALVIK-LABEL** полностью готово для запуска на любых компьютерах под управлением Windows / Linux без необходимости предварительной установки интерпретатора Python или дополнительных библиотек.

---

## 1. Запуск готового файла на любом компьютере

1. Скопируйте файл `MALVIK-LABEL.exe` (или исполняемый файл `MALVIK-LABEL`) из папки `dist/` на нужный ПК.
2. Запустите файл двойным кликом.
3. Программа автоматически:
   - Инициализирует базу данных SQLite (`malvik_label.db`) рядом с файлом, если её ещё нет.
   - Подберет свободный сетевой порт (по умолчанию `8000`).
   - Запустит веб-сервер и автоматически откроет браузер со страницей выбора рабочей роли (`http://127.0.0.1:8000` или выбранный порт).

---

## 2. Сборка нового EXE файла в один клик (Windows)

Если вы внесли изменения в исходный код или шаблоны и хотите собрать свежую версию `.exe`:

1. Нажмите двойным кликом на скрипт **`build_win.bat`**.
2. Скрипт автоматически установит требуемые пакеты через `pip` и выполнит сборку с помощью `PyInstaller`.
3. Готовый бинарный файл появится в папке `dist/MALVIK-LABEL.exe`.

---

## 3. Сборка через командную строку (Linux / macOS / Windows)

```bash
# Установка PyInstaller
pip install pyinstaller -r requirements.txt

# Сборка исполняемого файла по подготовленному спецификатору
pyinstaller MALVIK-LABEL.spec --noconfirm
```

Готовый файл располагается в каталоге `dist/`.
