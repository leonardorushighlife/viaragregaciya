# Автоматизация склада Wildberries

Это приложение на Python предназначено для автоматизации процесса сборки заказов на складе Wildberries. Оно интегрируется с Telegram-ботом для приема файлов заказов и отправки результатов.

## Основные возможности

- Прием файлов `.xlsx` через Telegram-бота от администратора.
- Ручная загрузка файлов через интерфейс.
- Табличное отображение заказа.
- Поддержка сканера штрих-кодов (эмуляция клавиатуры) для ввода КИЗ (Честный ЗНАК).
- Автоматическое заполнение Excel-шаблона.
- Отправка заполненного файла менеджеру в Telegram после завершения сборки.
- Статистика времени сборки.
- Поддержка прокси (HTTP/SOCKS5) для работы Telegram в России.

## Установка и настройка

### 1. Подготовка окружения
1. Установите Python 3.9 (рекомендуется для стабильности).
2. Распакуйте проект в рабочую папку.
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

### 2. Настройка Telegram-бота
1. Найдите [@BotFather](https://t.me/BotFather) в Telegram.
2. Используйте команду `/newbot`, дайте боту имя и получите **API Token**.
3. Чтобы бот работал только с вами, узнайте свой **Chat ID** (через [@userinfobot](https://t.me/userinfobot)).
4. Заполните файл `config.ini`:
   - `api_token`: Токен вашего бота.
   - `admin_chat_id`: Ваш ID (бот будет принимать файлы только от вас).
   - `receiver_chat_id`: ID менеджера или чата, куда отправлять готовые файлы.
   - `proxy_url`: Если Telegram заблокирован, укажите прокси, например: `socks5://user:pass@ip:port`.

### 3. Запуск
```bash
python main.py
```

## Сборка в .exe (Windows)

Для создания одного исполняемого файла:
```bash
pyinstaller --onefile --windowed --name "WB_Warehouse" main.py
```
Файл появится в папке `dist`.

## Сборка для Android

Поскольку приложение использует **PySide6**, для сборки под Android рекомендуется использовать инструменты **PySide6-Android** или **Briefcase** (от проекта BeeWare).

**Важные нюансы для Android:**
1. Интерфейс на PySide6 кроссплатформенный, но для мобильных устройств может потребоваться адаптация размеров элементов.
2. Для сборки используйте `briefcase`:
   - `pip install briefcase`
   - `briefcase create android`
   - `briefcase build android`
   - `briefcase run android`
3. Убедитесь, что все зависимости из `requirements.txt` поддерживаются на Android (openpyxl и aiogram работают корректно).

## Инструкция для работника склада

1. Запустите программу.
2. **Получение заказа**:
   - Отправьте боту в Telegram файл Excel. Окно сборки откроется автоматически.
   - Или нажмите "Загрузить заказ" и выберите файл на компьютере.
3. Нажмите **"Начать сборку"**. Включится таймер.
4. Сканируйте код маркировки товара. Курсор должен быть в поле "Сканер".
5. Программа автоматически найдет товар в списке и отметит его как "Собрано".
6. После сканирования всех товаров нажмите **"Завершить сборку"**.
7. Программа покажет отчет и отправит готовый файл в Telegram менеджеру.
