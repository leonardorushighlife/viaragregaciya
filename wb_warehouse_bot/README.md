# Автоматизация склада Wildberries

Это приложение на Python предназначено для автоматизации процесса сборки заказов на складе Wildberries. Оно интегрируется с Telegram-ботом для приема файлов заказов и отправки результатов.

## Основные возможности

- Прием файлов `.xlsx` через Telegram-бота от администратора.
- Ручная загрузка файлов через интерфейс.
- Табличное отображение заказа.
- Поддержка сканера штрих-кодов (автоматическая конвертация русской раскладки в английскую).
- Автоматическое заполнение Excel-шаблона.
- Отправка заполненного файла и отчета менеджерам в Telegram.
- **Статистика сборок**: возможность просмотра агрегированных данных за неделю, месяц и за все время.
- Поддержка прокси (HTTP/SOCKS5) для работы Telegram в России.
- Совместимость с PySide6 и PyQt5.

## Установка и настройка

### 1. Подготовка окружения
1. Установите Python 3.9 - 3.12.
2. Распакуйте проект в рабочую папку.
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

### 2. Настройка Telegram-бота
1. Бот уже преднастроен, но вы можете изменить токен и ID в `config.ini`.
2. Список ID админов и получателей: `341302561, 814456463, 748105161, 535900388`.
3. Чтобы получать отчеты, пользователь должен нажать `/start` в боте.

### 3. Запуск
```bash
python main.py
```

## Статистика
Программа сохраняет историю каждой завершенной сборки в файл `assembly_history.json`. Вы можете просмотреть суммарную статистику (количество сборок, товаров и затраченное время), нажав кнопку **"Показать статистику"** на главном окне.

## Сборка в .exe (Windows)

Для создания одного исполняемого файла:
```bash
pyinstaller --onefile --windowed --name "WB_Warehouse" main.py
```

## Инструкция для работника склада

1. Запустите программу.
2. **Получение заказа**: Отправьте боту в Telegram файл Excel или загрузите вручную.
3. Нажмите **"Начать сборку"**.
4. Сканируйте код маркировки товара. Программа сама поймет ввод даже при русской раскладке.
5. После сканирования всех товаров нажмите **"Завершить сборку"**.
6. Отчет автоматически уйдет в Telegram менеджерам.
