# Автоматизация склада Wildberries

Это приложение на Python предназначено для автоматизации процесса сборки заказов на складе Wildberries. Оно интегрируется с Telegram-ботом для приема файлов заказов и отправки результатов.

## Основные возможности

- Прием файлов `.xlsx` через Telegram-бота от администратора.
- Ручная загрузка файлов через интерфейс.
- Табличное отображение заказа.
- Поддержка сканера штрих-кодов (эмуляция клавиатуры) для ввода КИЗ (Честный ЗНАК).
- Автоматическое заполнение Excel-шаблона.
- Отправка заполненного файла менеджеру в Telegram после завершения сборки.
- Статистика времени сборки.
- Поддержка прокси для работы Telegram в России.

## Установка и настройка

### 1. Подготовка окружения
1. Установите Python 3.9 или выше.
2. Склонируйте или распакуйте проект.
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

### 2. Настройка Telegram-бота
1. Создайте бота через [@BotFather](https://t.me/BotFather) в Telegram и получите API Token.
2. Узнайте свой `chat_id` (например, через [@userinfobot](https://t.me/userinfobot)).
3. Заполните `config.ini`:
   - `api_token`: Токен вашего бота.
   - `admin_chat_id`: Ваш ID (от кого бот будет принимать файлы).
   - `receiver_chat_id`: ID менеджера или чата, куда отправлять результаты.
   - `proxy_url`: (Опционально) Например, `http://user:pass@ip:port`.

### 3. Запуск
```bash
python main.py
```

## Сборка в .exe

Для создания исполняемого файла используйте PyInstaller:

```bash
pyinstaller --onefile --windowed --name "WB_Warehouse" main.py
```

Готовый файл появится в папке `dist`.

## Инструкция для работника склада

1. Запустите программу `WB_Warehouse.exe`.
2. **Получение заказа**:
   - Отправьте Excel-файл заказа боту в Telegram. Программа автоматически откроет окно сборки.
   - ИЛИ нажмите "Загрузить заказ" и выберите файл вручную.
3. В окне сборки нажмите **"Начать сборку"**.
4. Берите товар, сканируйте его код маркировки (DataMatrix/Честный ЗНАК).
5. Программа сама найдет нужную строку и впишет КИЗ.
6. Когда все товары отсканированы, нажмите **"Завершить сборку"**.
7. Программа покажет время работы и автоматически отправит заполненный файл менеджеру.
