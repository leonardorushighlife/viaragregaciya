ПОДРОБНАЯ ИНСТРУКЦИЯ ПО НАСТРОЙКЕ И ЗАПУСКУ

1. УСТАНОВКА И ПОДГОТОВКА:
   - Установите Python 3.9 - 3.12. (Версия 3.12.x подходит).
   - При установке ОБЯЗАТЕЛЬНО отметьте "Add Python to PATH".
   - Обновите установщик пакетов:
     python -m pip install --upgrade pip
   - Установите библиотеки:
     pip install -r requirements.txt

   *ВАЖНО:* Если PySide6 не устанавливается, попробуйте установить PyQt5:
   pip install PyQt5

3. РЕДАКТИРОВАНИЕ КОНФИГУРАЦИИ (config.ini):
   - api_token = Ваш токен (уже вставлен).
   - admin_chat_id = ID админов (уже вставлены).
   - receiver_chat_id = ID получателей (уже вставлены).
   - proxy_url = Ваш прокси (если бот не подключается).
     Пример: socks5://user:password@ip:port

4. ОСОБЕННОСТИ РАБОТЫ:
   - РАСКЛАДКА: Программа автоматически переводит ввод с русской раскладки в английскую. Вам не нужно переключать язык на компьютере.
   - ОТЧЕТЫ: После завершения сборки программа автоматически отправляет отчет в Telegram.
   - ОШИБКА "Chat not found": Получатель должен хотя бы раз написать боту /start.
