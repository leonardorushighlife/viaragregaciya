ИНСТРУКЦИЯ ПО УСТАНОВКЕ И СБОРКЕ

1. УСТАНОВКА PYTHON:
   - Скачайте и установите Python 3.9.x с официального сайта python.org.
   - При установке обязательно отметьте галочку "Add Python to PATH".

2. УСТАНОВКА БИБЛИОТЕК:
   - Откройте командную строку (cmd) в папке с проектом.
   - Выполните: pip install -r requirements.txt

3. СОЗДАНИЕ ТЕЛЕГРАМ-БОТА:
   - Напишите @BotFather в Telegram.
   - Используйте команду /newbot и следуйте инструкциям.
   - Скопируйте полученный API Token.

4. НАСТРОЙКА CONFIG.INI:
   - Откройте config.ini в текстовом редакторе.
   - api_token = Ваш токен.
   - admin_chat_id = Ваш ID (можно узнать у @userinfobot).
   - receiver_chat_id = ID получателя результатов.
   - proxy_url = Ваш прокси (если нужен).

5. СБОРКА В .EXE:
   - В командной строке выполните:
     pyinstaller --onefile --windowed --icon=app_icon.ico main.py
   - Если иконки нет, уберите флаг --icon.
   - Итоговый файл будет в папке dist.

6. ИСПОЛЬЗОВАНИЕ:
   - Запустите программу.
   - Отправьте боту .xlsx файл.
   - В программе появится таблица.
   - Нажмите "Начать сборку".
   - Сканируйте коды Честный ЗНАК.
   - Нажмите "Завершить сборку".
   - Файл отправится менеджеру автоматически.
