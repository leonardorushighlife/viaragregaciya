ПОДРОБНАЯ ИНСТРУКЦИЯ ПО НАСТРОЙКЕ И ЗАПУСКУ

1. УСТАНОВКА И ПОДГОТОВКА:
   - Установите Python 3.9 с сайта python.org. При установке ОБЯЗАТЕЛЬНО отметьте "Add Python to PATH".
   - Скачайте файлы проекта и откройте командную строку (cmd) в этой папке.
   - Установите библиотеки: pip install -r requirements.txt

2. НАСТРОЙКА ТЕЛЕГРАМ:
   - Напишите @BotFather в Telegram, создайте бота (/newbot) и получите ТОКЕН.
   - Напишите @userinfobot, чтобы узнать свой ID (это будет admin_chat_id).
   - Чтобы бот мог отправлять отчеты получателю, получатель ДОЛЖЕН ПЕРВЫМ написать боту /start.
   - Узнайте ID получателя и вставьте в receiver_chat_id.

3. РЕДАКТИРОВАНИЕ КОНФИГУРАЦИИ (config.ini):
   - api_token = Ваш токен.
   - admin_chat_id = Ваш ID.
   - receiver_chat_id = ID получателя результатов (менеджера).
   - proxy_url = Ваш прокси (если бот не подключается).
     Пример: socks5://user:password@ip:port

4. ОСОБЕННОСТИ РАБОТЫ:
   - РАСКЛАДКА: Программа автоматически переводит ввод с русской раскладки в английскую. Вам не нужно переключать язык на компьютере.
   - ОТЧЕТЫ: После завершения сборки программа автоматически отправляет подробный отчет вместе с файлом в Telegram. Окно с отчетом в самой программе больше не мешает работе.
   - ОШИБКА "Chat not found": Означает, что ID получателя указан неверно или получатель еще не написал боту /start.

5. СБОРКА .EXE:
   - В командной строке: pyinstaller --onefile --windowed --name WB_Warehouse main.py
   - Готовый файл в папке dist.
