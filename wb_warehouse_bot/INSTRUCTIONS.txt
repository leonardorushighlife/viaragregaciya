ПОДРОБНАЯ ИНСТРУКЦИЯ ПО НАСТРОЙКЕ И ЗАПУСКУ

1. УСТАНОВКА И ПОДГОТОВКА:
   - Установите Python 3.9 с сайта python.org. При установке ОБЯЗАТЕЛЬНО отметьте "Add Python to PATH".
   - Скачайте файлы проекта и откройте командную строку (cmd) в этой папке.
   - Установите библиотеки: pip install -r requirements.txt

2. НАСТРОЙКА ТЕЛЕГРАМ:
   - Напишите @BotFather в Telegram, создайте бота (/newbot) и получите ТОКЕН.
   - Напишите @userinfobot, чтобы узнать свой ID (это будет admin_chat_id).
   - Если нужно отправлять отчеты другому человеку, узнайте также его ID (receiver_chat_id).

3. РЕДАКТИРОВАНИЕ КОНФИГУРАЦИИ:
   - Откройте config.ini в Блокноте.
   - Вставьте токен в api_token.
   - Вставьте свой ID в admin_chat_id.
   - Вставьте ID получателя в receiver_chat_id.
   - Если бот не подключается (нужен VPN/Прокси), вставьте ссылку на прокси в proxy_url.
     Пример: socks5://user:password@ip:port

4. ЗАПУСК И СБОРКА .EXE:
   - Запуск для проверки: python main.py
   - Сборка в один файл для Windows:
     pyinstaller --onefile --windowed --name WB_Warehouse main.py
   - Готовый файл WB_Warehouse.exe заберите из папки dist.

5. ПЕРЕНОС НА АНДРОИД:
   - Код написан на PySide6, который поддерживает Android.
   - Для сборки .apk используйте инструмент BeeWare Briefcase или PySide6-android.
   - Обратите внимание, что на телефоне сканер штрих-кодов обычно работает как Bluetooth-клавиатура или через камеру (потребуется дополнительная доработка для использования камеры).

6. ПОРЯДОК РАБОТЫ:
   - Программа всегда должна быть запущена на компьютере/устройстве.
   - Вы (админ) кидаете файл Excel боту.
   - Программа на складе "подхватывает" файл и открывает таблицу.
   - Работник сканирует КИЗы, они заполняются в таблицу.
   - После нажатия "Завершить", заполненный файл летит менеджеру.
