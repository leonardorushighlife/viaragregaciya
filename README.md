# MALVIK-LABEL — Внутренняя система маркировки и фасовки

Веб-система автоматизации процессов передачи заказов на фасовку, запроса и печати кодов маркировки (Честный Знак), нанесения этикеток операторами фасовки и формирования финальной отчетности.

---

## 📌 Архитектура и технологии

- **Бэкенд**: Python 3.11+, FastAPI, SQLAlchemy 2.0, Alembic, SQLite
- **Фронтенд**: Jinja2 HTML-шаблоны, Bootstrap 5, HTMX (уведомления через polling), PWA (Progressive Web App для оператора)
- **Планировщик**: APScheduler (фоновая проверка сроков отгрузки за 2 дня)
- **Email**: `aiosmtplib` (заглушка/отключен по умолчанию)
- **Честный Знак**: Интеграция с абстрактным интерфейсом сервиса кодов маркировки (заглушка `MockChestnyZnakService`)

---

## 🚀 Подробная инструкция по запуску

### 1. Системные требования
- Python версии **3.11** или новее.
- Утилита `git` (при необходимости).

### 2. Клонирование репозитория и переход в директорию
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd MALVIK-LABEL
```

### 3. Создание и активация виртуального окружения

**Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows (CMD / PowerShell):**
```cmd
python -m venv venv
venv\Scripts\activate
```

### 4. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 5. Настройка переменных окружения (опционально)
Создайте файл `.env` в корневой директории проекта, если необходимо переопределить стандартные настройки:
```env
PROJECT_NAME="MALVIK-LABEL"
DATABASE_URL="sqlite:///./malvik_label.db"
EMAIL_ENABLED=False
SMTP_HOST="smtp.gmail.com"
SMTP_PORT=587
SMTP_USER=""
SMTP_PASSWORD=""
EMAIL_FROM="noreply@malvik.ru"
CHESTNY_ZNAK_STUB=True
```

### 6. Применение миграций базы данных
База данных SQLite создастся автоматически в файле `malvik_label.db`:
```bash
alembic upgrade head
```

### 7. Запуск веб-сервера
Запустите сервер приложений Uvicorn:
```bash
python main.py
```
Или напрямую через uvicorn:
```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

После запуска приложение будет доступно по адресу: **http://localhost:8000**

## 👥 Роли и пользовательские интерфейсы

### 1. Фасад / Менеджер фасовки (`http://localhost:8000/facade`)
- Создание и редактирование заказов на фасовку.
- Настройка внутренних наименований продукции для своего отдела.
- Отправка заказов в отдел маркировки (с опциональной отправкой Email-уведомления).

### 2. Отдел Маркировки (`http://localhost:8000/labeling`)
- Отдельный интерфейс без возможности создания заказов.
- Запрос кодов маркировки в Честном Знаке (заглушка генерации кодов).
- Отметка о печати кодов.
- Автоматическое предупреждение за **2 дня до даты отгрузки**.
- Сдача и подтверждение итоговых отчетов по наклеенным и испорченным кодам.

### 3. Оператор Фасовки / PWA Touch-screen (`http://localhost:8000/operator`)
- Адаптированный сенсорный интерфейс с крупным шрифтом для планшетов и экранов фасовки.
- Поддержка PWA (возможность добавить иконку на рабочий стол).
- Экран выполнения задачи с крупными кнопками `+1`, `+10` и экранной клавиатурой для ручного ввода.
- Таймер времени выполнения задачи.
- Диалог завершения задачи с вводом остатка этикеток и автоблокировкой задачи после финиша.
